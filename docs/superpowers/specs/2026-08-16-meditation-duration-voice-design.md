# 冥想时长预设与语音输入设计

## 目标

为三个冥想方式统一增加 1 分钟、30 分钟和 60 分钟的预设，并允许用户在时长选择页通过语音输入自定义时长。语音中出现小时单位时，统一换算为分钟；例如“1 小时 30 分钟”转换为 90 分钟。

## 范围与现状

- 三个方式（呼吸冥想、身体扫描、静坐）当前共用 `aiui-agent/pages/meditation/meditation.ink` 的时长状态、选择器和语音命令路由。
- 本次只修改这一个页面及其自动化测试，不新增页面、不修改后端接口、不改变计时器、背景音和冥想方式选择流程。
- 现有接口约定冥想时长为 1–120 分钟，因此自定义语音时长沿用这个范围。

## 交互设计

### 预设选择

预设数组由 `[5, 10, 20]` 扩展为 `[1, 5, 10, 20, 30, 60]`。时长页的上下键仍在预设数组中循环；语音输入的自定义值仍显示在同一个时长选择器中，按 Enter 或语音确认后直接开始计时。

### 语音解析

时长页收到识别文本后，按以下顺序解析：

1. 识别小时与分钟的组合，计算 `小时 × 60 + 分钟`。
2. 若没有小时单位但包含分钟单位，读取分钟数。
3. 若没有单位，兼容阿拉伯数字和现有中文数字表达。
4. 解析结果必须为 1–120 的正整数；否则保持时长页，不启动计时，并显示无法识别或超出范围的提示。

支持的示例：

| 语音输入 | 结果 |
| --- | ---: |
| `1分钟` | 1 |
| `30分钟` | 30 |
| `60分钟` | 60 |
| `90分钟` | 90 |
| `1小时` | 60 |
| `两小时` | 120 |
| `1小时30分钟` | 90 |

中文数字解析至少覆盖 1–60 分钟常见表达，以及 1–2 小时；阿拉伯数字支持小时和分钟组合。保持现有返回数字的函数接口，避免改动语音命令路由和计时启动流程。

## 实现边界

- 将预设列表定义为页面时长选择的唯一来源，`durationIdx` 只用于预设上下键循环；自定义时长仍可显示并启动，不要求插入预设列表。
- `setDuration` 继续负责更新 `durationMinutes` 和 `timerText`，并把大于等于当前预设的索引逻辑调整为能安全处理自定义值。
- 语音解析函数保持纯函数式行为，不访问页面状态，便于在 Node 测试中直接验证。
- 不引入浏览器专属输入控件；继续复用现有 `SpeechRecognition` 生命周期和页面隐藏时的清理逻辑。

## 测试与验收

在现有 `aiui-agent/tests/meditation-white-noise.test.cjs` 中增加测试：

- 预设源码包含 1、30、60，且上下键能遍历全部六个预设。
- 纯分钟数字、分钟单位、小时单位和“小时+分钟”组合解析正确。
- 中文数字小时与分钟解析正确。
- 0 分钟、负数、超过 120 分钟和无法解析的文本返回无效结果，不进入计时。
