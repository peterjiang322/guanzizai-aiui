# 经文详情返回与列表外框设计

## 目标

修复读经页的两个触摸交互问题：

1. 在具体经文详情中双击触摸，只返回经文列表，不返回首页。
2. 经文列表中，当前选中卡片不显示外框，所有未选中卡片保留绿色外框。

## 双击返回

- 在读经页 `onKeyUp(event)` 收到 `Backspace` 时立即调用 `event.preventDefault()`，阻止宿主继续执行默认页面返回。
- 双击时间使用页面实例字段 `_lastBackspaceTime` 同步保存，不再依赖异步 `setData()`。
- 两次 `Backspace` 间隔小于 500ms 时：
  - 详情视图调用 `handleBack()`，切换回当前页面的经文列表。
  - 列表视图调用 `wx.navigateBack()`，返回首页。
- 单次 `Backspace` 只记录时间，不改变页面。

## 卡片外框

- 列表项使用动态 class 表达选中状态，移除当前长内联三元 `style`。
- `.card-wrap` 默认显示 `1px` 半透明绿色边框，代表未选中卡片。
- `.card-wrap-selected` 使用透明边框和绿色半透明背景，代表当前选中卡片。
- 两个状态均保留相同边框宽度，避免切换选中时发生尺寸跳动。

## 变更范围

- 修改 `pages/scripture/scripture.ink` 的双击时间字段、`handleBackspace()`、两处分支中的 `Backspace` 处理、列表项 class 和对应样式。
- 不修改 ASR 生命周期、经书名映射、经文加载、翻品或其他页面。
- 保留详情返回列表时 `selectedIdx: 0` 的现有行为。

## 验证

- 自动化测试证明详情视图的单次和双次 `Backspace` 都会阻止宿主默认返回，双击只将 `showingDetail` 设为 `false`，且不调用 `wx.navigateBack()`。
- 自动化测试证明列表视图双击仍调用一次 `wx.navigateBack()`。
- 自动化测试检查模板不再使用旧内联三元边框，并包含选中/未选中 class 与对应边框规则。
- 运行读经专项测试、全部 Node 回归测试和 `git diff --check`。

## 设备联调

- 进入任一具体经文后双击触摸，应显示经文列表而不是首页。
- 在列表中连续滑动选择，当前项应无边框并保留背景，所有离开选中状态的卡片应恢复绿色外框。
