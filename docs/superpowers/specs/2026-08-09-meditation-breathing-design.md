# 冥想倒计时呼吸效果设计

## 目标

冥想进行中，让倒计时数字与外圈同步进行平滑的“变暗 → 变亮”呼吸效果，增强专注感；暂停、完成和重置时停止呼吸更新。

## 交互参数

- 呼吸周期：6 秒。
- 变暗阶段：3 秒，从最亮逐渐降至最低亮度。
- 变亮阶段：3 秒，从最低亮度逐渐恢复至最亮。
- 呼吸因子范围：0.20 至 1.0；最终透明度仍叠加冥想时长的基础渐暗。
- 更新频率：100ms。
- 外圈和倒计时数字共用 `ringOpacity`，保证视觉同步。
- 外围增加一层绿色轮廓光晕，光晕强度随同一呼吸相位变化。
- 光晕缩放范围：约 0.96 至 1.08；变亮时放大，变暗时缩小。
- 光晕不使用 `transform: scale()`；每帧同步计算 `width`、`height`、`left`、`top`，将圆心固定在 194px 舞台的 `(97, 97)`。
- 倒计时外侧原有固定圆环、进度底色和内层圆底全部透明，仅保留倒计时文字与动态呼吸光晕。

## 实现方案

AIUI WXSS 不使用 `animation`，由页面 JavaScript 定时器驱动透明度变化：

1. 冥想开始或恢复时启动呼吸定时器。
2. 每次 tick 根据经过时间计算三角波相位，再映射到 0.20–1.0 的呼吸因子。
3. 通过 `setData({ ringOpacity })` 同步更新外圈和倒计时数字。
4. 通过 `setData({ haloStyle })` 更新外围绿色轮廓光晕的边框、填充强度、尺寸和居中偏移。
5. 暂停时清除定时器并保留当前透明度与光晕，恢复时从当前相位继续。
6. 倒计时完成或手动重置时清除定时器，将透明度恢复为 1 并隐藏光晕。

现有基于冥想经过时间的整体渐暗逻辑保留为基础亮度，呼吸透明度叠加在基础亮度之上，避免长时间冥想失去原有的渐暗层次。

## 验证

- running 状态启动呼吸定时器，paused/completed/idle 状态不继续更新。
- 呼吸因子始终在 0.20–1.0 范围内，并随时间先降后升；光晕强度同步变化。
- 暂停不会创建新的定时器，恢复后只创建一个定时器。
- 倒计时完成和重置后定时器被清理，`ringOpacity` 恢复为 1。
- 现有冥想音频、倒计时和跨页面播放测试保持通过。
