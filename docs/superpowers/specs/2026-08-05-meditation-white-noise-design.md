# 冥想集成白噪音设计

## 目标

暂时下线独立白噪音模块，将本地白噪音作为冥想背景音。用户开始冥想后，系统随机播放一个白噪音文件，以 15% 音量持续循环至冥想结束。

## 范围

- 从首页菜单、首页语音指令、欢迎播报与底部提示中移除“白噪音”入口。
- 从 `app.json` 的 `pages` 中移除 `pages/soundscape/soundscape`。
- 保留 `pages/soundscape/soundscape.ink` 和全部本地音频资源，便于以后恢复独立模块。
- 在 `pages/meditation/meditation.ink` 中集成随机选择、单曲间隔播放、暂停、恢复和清理逻辑。

## 音频资源

随机池固定为现有 6 个本地文件：

- `morning_temple.wav`
- `rain_zen.wav`
- `stream_forest.wav`
- `ocean_mindfulness.wav`
- `night_temple.wav`
- `incense_chamber.wav`

每次新建冥想会话时调用 `Math.random()` 选择一个文件。同一次冥想暂停后恢复时，保留已选中的文件，不再重新随机。

## 播放器设计

使用 `wx._bgm` 作为跨页面共享的唯一背景音播放器，其实例优先使用项目已验证的 `AudioPlayer`：

- `src` 指向本地相对路径。
- `loop = false`，由兼容性定时器按单曲时长手动重播。
- `volume = 0.15`。
- 根据冥想总时长和单曲时长计算播放次数：`ceil(totalSeconds * 1000 / loopMs)`。
- 使用同一个 `AudioPlayer` 实例重播同一首随机选中的音频。
- 如创建或播放失败，回退到 `Sound`。

`Sound` 回退只使用本地资源：

- `volume = 0.15`。
- 按现有文件时长表定时重播同一首音频，播放次数由冥想时长计算得出。
- 由于 `Sound` 无 `pause()`，暂停时停止实例，恢复时从同一个文件开头重播。

## 状态与生命周期

1. `startMeditation()` 初始化倒计时状态，随机选择音频并开始播放。
2. `togglePause()` 进入暂停时同步暂停音频；恢复倒计时时恢复同一个音频。
3. 倒计时归零时先停止并销毁播放器，再更新完成状态和播报完成语。
4. `resetMeditation()` 停止音频、循环定时器与引导文定时器，清空当前选中音频。
5. `onHide()` 只清理语音识别，不暂停或销毁 `wx._bgm`，确保页面跳转时音乐不中断。
6. `onUnload()` 只清理语音识别；背景音由冥想倒计时完成路径统一停止并销毁。

## 异常处理

- 音频播放失败不中断冥想倒计时，仅清理失败的播放器。
- 音频循环定时器只在当前播放器仍有效、冥想状态未暂停时触发。
- 重复开始新冥想前先清理旧音频，避免多实例叠加。

## 验证标准

- 首页无白噪音菜单、语音路由和提示文案。
- `app.json` 不再注册白噪音页，但页面文件和 6 个音频文件仍存在。
- 每次开始冥想只选择一个本地文件，播放音量为 `0.15`。
- 单曲按计算出的次数循环播放，直到倒计时完成。
- 暂停、恢复、手动结束、自然结束、隐藏页面和卸载页面均会执行对应的音频生命周期操作。
- 不引入 AIUI 未验证的远程音频或浏览器专属 API。
